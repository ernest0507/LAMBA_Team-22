# Week 3 LLM Usage Report

During Week 3, the team used AI/LLM tools to support documentation, writing, translation, and development-related tasks.

ChatGPT was used to translate customer meeting materials into English, clean transcript text, correct grammar and punctuation, and improve the clarity of report wording. LLM tools also helped prepare structured documentation, including the customer meeting transcript, meeting summary, reflection, retrospective, and other report sections.

AI/LLM tools were used to help refine formulations in backlog-related documentation, acceptance criteria, and sprint-related notes. The team used LLM assistance to make the wording more consistent, readable, and aligned with the assignment requirements.

New in Week 3, the team also used LLM tools to support development work. In several parts of the codebase, AI assistance was used to identify mistakes, suggest fixes, and improve parts of the implementation. The team used these suggestions as support while debugging and refining the code, but the final decisions and code changes were reviewed and applied by the developers.

All AI-assisted outputs were checked by the team before being added to the repository. The team treated LLM tools as assistants for translation, editing, documentation, and code refinement, while keeping responsibility for the final content and implementation.
