LAMBA: документация по единым стилям

Простая памятка по готовым переменным дизайна. Использовать для всех экранов приложения: главный экран, AI-чат, гараж, история, статистика, документы, профиль, onboarding и создание цифрового двойника.

Цвета

Фон приложения: LambaCanvas

Используется как основной фон всех светлых экранов: гараж, статистика, документы, история, профиль, onboarding, создание цифрового двойника.

Основная поверхность: LambaSurface

Используется для карточек, панелей, списков, крупных блоков, bottom sheets, drawer-меню и светлых контейнеров поверх фона.

Мягкая поверхность: LambaSurfaceSoft

Используется для полей ввода, вторичных блоков, фона внутри карточек, icon surfaces, composer-поля в чате и мягких подсказок.

Основной текст: LambaInk

Используется для заголовков, основного текста, значений, выбранных элементов, названий документов, пунктов меню и важных сумм.

Вторичный текст: LambaInkMuted

Используется для подписей, метаданных, описаний, placeholder-текста, дат, “Шаг 1 из 2”, пробега, размеров файлов и helper-текста.

Основной акцент: LambaAccent

Используется для активных состояний: выбранная вкладка, progress bar, выбранный swatch, активная иконка, выделенный border, интерактивный акцент.

Сильный акцент: LambaAccentStrong

Используется для главных кнопок, send-кнопки, важных активных элементов, круглых success-иконок и темных petrol-акцентов.

Мягкий акцент: LambaAccentSoft

Используется для вторичных кнопок, активных светлых chips, мягких иконок, подсветки выбранного состояния без сильного визуального веса.

Фон AI-чата: LambaChat

Используется для основной темной зоны AI-чата и специальных assistant-поверхностей, которые должны отличаться от светлой части приложения.

Средний тон AI-чата: LambaChatMid

Используется как промежуточный цвет в градиенте AI-чата, drawer-акцентах и темных assistant-блоках.

Глубокий тон AI-чата: LambaChatDark

Используется для нижней или самой темной части chat-gradient, затемнения и создания глубины в AI-зоне.

Текст на темном чате: LambaChatInk

Используется для текста, иконок и легких элементов поверх темного AI-чата, если обычный LambaInk недостаточно контрастный.

Сигнальный цвет: LambaSignal

Используется точечно для предупреждений, сервисных сигналов, маленьких маркеров внимания и важных автомобильных событий. Не использовать как основной цвет экрана.

Основная граница: LambaOutline

Используется для border у карточек, полей, chips, list items, кнопок второго уровня и отделения поверхностей друг от друга.

Мягкая граница: LambaOutlineSoft

Используется для тонких разделителей, неактивного progress bar, легких рамок, divider-линий в списках и низкоконтрастных элементов.

Ошибка: LambaError

Используется для ошибок валидации, критичных предупреждений, неуспешных действий и состояния поля с ошибкой.

Цвета автомобиля

Серебристый: LambaVehicleSilver

Используется как базовый нейтральный цвет автомобиля по умолчанию.

Графитовый: LambaVehicleGraphite

Используется для более строгого и технического образа автомобиля.

Синий: LambaVehicleBlue

Используется для холодного варианта автомобиля, который хорошо сочетается с petrol-палитрой.

Зеленый: LambaVehicleGreen

Используется для спокойного eco-tech варианта автомобиля.

Красный: LambaVehicleRed

Используется для теплого варианта автомобиля, но без слишком яркого спортивного эффекта.

Отступы

Базовый шаг: LambaSpacing.Step

Используется как ритм для мелких расстояний и кратных значений: 4dp, 8dp, 12dp, 16dp, 20dp, 24dp, 32dp.

Горизонтальные отступы экрана: LambaSpacing.ScreenHorizontal

Используется для основного контента на всех экранах приложения: формы, списки, карточки, чат, профиль, статистика, документы.

Верхний отступ экрана: LambaSpacing.ScreenTop

Используется для верхней зоны экрана: кнопка назад, заголовок, меню, статусный блок, начало основного контента.

Нижний безопасный отступ: LambaSpacing.ScreenBottom

Используется для обычных экранов без фиксированной нижней кнопки или нижней навигации.

Отступ внутри карточек и полей: LambaSpacing.CardPadding

Используется внутри карточек, input-полей, list items, подсказок, AI-bubbles, document rows, statistic cards и success-блоков.

Отступ под нижнюю навигацию/нижнюю кнопку: LambaSpacing.BottomNavigationSpace

Используется, если снизу закреплена основная кнопка, composer чата, bottom navigation или зона, которую нельзя перекрывать контентом.

Радиусы

Малый радиус: LambaRadius.Small

Используется для маленьких chips, бейджей, компактных controls, маленьких подсказок, внутренних icon surfaces и небольших статусных элементов.

Средний радиус: LambaRadius.Medium

Используется для input-полей, обычных карточек, list items, кнопок, chips выбора, document rows и элементов формы.

Большой радиус: LambaRadius.Large

Используется для крупных карточек, chat-контейнеров, больших preview-блоков, панелей, success-блоков и основных секций экрана.

Pill radius: LambaRadius.Pill

Используется для полностью скругленных элементов: кнопка назад, tabs, segmented controls, search/composer bar, круглые swatches, progress segments, icon buttons.

Типографика

Главный заголовок: MaterialTheme.typography.headlineLarge

Используется для крупных onboarding-заголовков, hero-заголовков и ключевых экранов, где нужно сильное первое сообщение.

Заголовок экрана: MaterialTheme.typography.headlineMedium

Используется для основных заголовков экранов: “История”, “Статистика”, “Документы”, “Профиль”, “Настройте автомобиль”.

Компактный заголовок экрана: MaterialTheme.typography.titleLarge

Используется, когда заголовок должен быть заметным, но экран плотный: формы, модальные окна, bottom sheets, side drawer.

Заголовок секции: MaterialTheme.typography.titleMedium

Используется для заголовков карточек и секций: “Расходы по месяцам”, “Цвет автомобиля”, “Тип кузова”, названия пунктов меню.

Крупный основной текст: MaterialTheme.typography.bodyLarge

Используется для текста основных кнопок, крупных значений, важных строк и элементов, которые должны читаться быстрее обычного текста.

Основной текст: MaterialTheme.typography.bodyMedium

Используется для обычного текста интерфейса: значения в полях, сообщения, описания, текст карточек, строки списков.

Вторичный текст: MaterialTheme.typography.bodySmall

Используется для описаний, helper-текста, метаданных, подписей под заголовками, дат, размера файлов и пояснений.

Микро-подпись: MaterialTheme.typography.labelSmall

Используется для labels над полями, “Шаг 1 из 2”, маленьких chips, технических подписей, коротких статусов и kicker-текста.

Компоненты

Основная кнопка

Фон: LambaAccentStrong. Текст: белый. Радиус: LambaRadius.Medium. Типографика: bodyLarge. Используется для главного действия экрана.

Вторичная кнопка

Фон: LambaAccentSoft или LambaSurface. Текст: LambaAccentStrong или LambaInk. Радиус: LambaRadius.Medium. Используется для дополнительного действия.

Кнопка назад

Фон: LambaSurface. Радиус: LambaRadius.Pill. Иконка: LambaAccentStrong. Используется в верхней зоне вложенных экранов.

Поле ввода

Фон: LambaSurfaceSoft. Border: LambaOutline. Радиус: LambaRadius.Medium. Внутренний отступ: LambaSpacing.CardPadding.

Карточка

Фон: LambaSurface. Border: LambaOutline или LambaOutlineSoft. Радиус: LambaRadius.Medium для обычной карточки и LambaRadius.Large для крупной секции.

List item

Фон: LambaSurface. Текст: LambaInk. Метаданные: LambaInkMuted. Радиус: LambaRadius.Medium. Используется для истории, документов, пунктов меню.

Chip

Неактивный фон: LambaSurface. Активный фон: LambaSurfaceSoft. Активный border: LambaAccent. Радиус: LambaRadius.Medium или LambaRadius.Pill, если chip короткий и капсульный.

Progress bar

Активная часть: LambaAccent. Неактивная часть: LambaOutlineSoft. Радиус: LambaRadius.Pill. Используется в onboarding, формах и пошаговых сценариях.

AI chat area

Фон: LambaChat, LambaChatMid, LambaChatDark. Текст поверх темного фона: LambaChatInk. User message и send action: LambaAccent или LambaAccentStrong.

AI bubble

Фон AI-сообщения: LambaSurface. Текст: LambaInk. Радиус: LambaRadius.Medium. Внутренний отступ: LambaSpacing.CardPadding.

Composer / поиск

Фон: LambaSurfaceSoft или LambaSurface. Радиус: LambaRadius.Pill. Иконки: LambaInkMuted. Активная send-кнопка: LambaAccentStrong.
