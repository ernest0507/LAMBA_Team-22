## Learning points

During the second week, our team learned the idea of user stories. We practiced making user stories related to our application. Also, we learned how to prioritize user stories according to the MoSCoW method. We made a few prototype versions in Figma and chose the best one.
During the MVP v0 development stage, we made a runnable application using Kotlin in Android Studio. The project consists only of frontend development without a backend connection. Moreover, we discussed with the customer the first design prototype and its cons and pros.

## Validated assumptions

We assumed that the design of the application in terms of colors and fonts should be revised.
Also, we assumed that the panel of the chat with the AI assistant should take more space on the main screen.
We assumed that we should make documentation of the main colors, fonts, paddings, and other design elements to make the development process more stable.

## Needs clarification

We need to determine how application data will be stored and synchronized because MVP v0 currently has no backend or persistent database.
