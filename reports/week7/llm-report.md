# Week 7 LLM Report

## Overview

During Week 7, the team used Large Language Models (LLMs) as supporting tools during the final delivery stage of the project.

LLM assistance was used for documentation preparation, requirement analysis, and improving the clarity of project materials.

## Areas where LLMs were used

### Documentation support

LLMs were used to help:

- structure customer-facing documentation;
- improve wording and readability;
- review deployment and handover documentation;
- check whether required sections were covered.

### Assignment requirement analysis

LLMs were used to:

- review assignment requirements;
- identify missing report sections;
- compare prepared materials against required deliverables;
- organize the final submission workflow.

### Report preparation

LLMs helped with:

- improving Markdown formatting;
- preparing reflection and retrospective documents;
- creating consistent descriptions of completed work;
- reviewing final report structure.

### Technical documentation assistance

LLMs were used as a support tool when preparing:

- deployment instructions;
- handover documentation;
- environment configuration explanations;
- customer-oriented explanations of technical decisions.

## Human verification

All generated content was reviewed by team members before being included in project documentation.

The team remained responsible for:

- technical accuracy;
- final decisions;
- project implementation;
- customer communication;
- release preparation.

LLMs were used only as a productivity and writing assistance tool.

## Final reflection

Using LLM tools helped the team organize the final delivery stage more efficiently, especially when preparing documentation and checking compliance with project requirements.

The experience showed that LLMs are useful for improving documentation quality and reducing time spent on repetitive writing tasks, while human review remains necessary for correctness and project-specific decisions.
