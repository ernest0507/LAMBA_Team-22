## QR-001: Response time in registration flow

**ISO/IEC 25010 characteristic:** Performance efficiency  
**ISO/IEC 25010 sub-characteristic:** Time behaviour

**Scenario:** When 20 users concurrently submit correctly filled fields of the registration form under the standart CI enviroment, the backend API shall return response at least fo 90% users within 2 seconds

**Why this matters:** Users need quick access to their profiles. Slow registration responses prevent new users from registering
