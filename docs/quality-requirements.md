## QR-001: Response time in registration flow

**ISO/IEC 25010 sub-characteristic:** Performance Efficiency - Time behaviour

**Scenario:** When user submit data with correctly filled fields of the registration form API shall return a response within 2 seconds for 90% of requests with 20 concurrent users 

**Why this matters:** Users need quick access to their profiles. Slow registration responses prevent new users from registering
