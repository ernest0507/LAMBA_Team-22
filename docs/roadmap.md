# Roadmap

## Sprint 1 — MVP v1

**Milestone:** [Sprint 1 - MVP v1](https://github.com/ernest0507/LAMBA_Team-22/milestone/1)  
**Dates:** 15-06-2026 – 21-06-2026  

**Sprint Goal:**  
Deliver the MVP v1 mobile flow that lets a car owner create an account, create a basic digital twin, and navigate between the main MVP screens.

**Focus / expected outcome:**  
The Sprint focuses on moving from the earlier prototype/MVP v0 direction toward a more integrated MVP v1. The expected outcome is a mobile product increment with backend-connected product foundations, basic digital twin data flow, AI-assistant chat integration work, and navigation between the main MVP screens.

**Planned items:**

- [US-01: Storing car's data](https://github.com/ernest0507/LAMBA_Team-22/issues/31)
- [PBI - Integrating the chat with AI-assistant](https://github.com/ernest0507/LAMBA_Team-22/issues/49)
- [PBI - Implement MVP v1 navigation between screens](https://github.com/ernest0507/LAMBA_Team-22/issues/51)
