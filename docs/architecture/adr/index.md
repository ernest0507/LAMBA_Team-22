# Architecture Decision Records Directory

This directory stores the Architecture Decision Record files for the LAMBA project.

ADR files must use the course-required filename pattern:

```text
ADR-001-short-description.md
```

The main maintained ADR index is the [Architecture Overview](../), because `docs/architecture/README.md` is the canonical maintained architecture index for the project.

Each ADR should explain:

- the decision that was made;
- the context and problem addressed;
- the alternatives considered;
- the consequences of the decision;
- the related quality requirement or quality requirements.
